## 🚀 How to Run Locally

If you modify **any** of the 59 `.cpp` files natively, you **MUST** re-bundle the cache for the frontend web browser to recognize the update.

1. Ensure Python 3.10+ is natively operating dynamically in your PATH sequence.
2. In your terminal, run the master builder executable:
```bash
python builder.py
```
3. Boot `index.html` natively in any web-browser natively. The AST maps and pseudo-Simulators will intelligently absorb your new file changes.
